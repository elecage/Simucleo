# ADR 0004: 브레드보드 배선 편집기와 hot-plug

- 상태: 채택 (2026-11-18)

## 결정
- 실제 모양과 비슷한 **브레드보드 뷰**를 먼저 만든다. 회로도 뷰는 나중에 추가한다.
- 0.1인치 그리드. 서로 다른 부품의 핀이 같은 점에 있으면 연결된다(리드를 브레드보드에 꽂는 동작).
- 부품 내부 연결(브레드보드 행·레일, 스위치 단자, Nucleo의 같은 신호 핀)은 `buses`로 선언한다.
- Nucleo 보드는 **Arduino 헤더와 Morpho 헤더(CN7/CN10)를 모두** 제공한다. 같은 MCU 신호 핀끼리는 내부 버스로 묶는다.
- **핀 정보는 별도 핀맵 문서 없이 GUI에 표시**한다. 실제 보드의 실크스크린처럼 모든 헤더 핀 옆에 이름(Morpho는 MCU 신호명, Arduino는 D/A 이름)을 쓰고, 종류별 색상(GPIO, 보드 내장, ST-LINK/크리스털 사용, 전원, GND, NC)과 범례, 헤더 양 끝 핀 번호(1/2, 37/38)를 넣는다. 브레드보드에도 행 문자(a–j), 열 번호, 레일 극성을 표시하고, 마우스를 올리면 `CN10-11 · PA5 · LD2 · SCK` 같은 상세 정보를 보여 준다.
- **실행 중 배선 변경(hot-plug)을 허용**한다. 편집할 때마다 Circuit JSON을 코어에 다시 보내고, 코어는 넷리스트를 다시 만든다.
- 부품 그래픽은 직접 제작한다. CC-BY-SA 부품 라이브러리와 제조사 로고는 사용하지 않는다.

## 결과
- 넷리스트 추출은 Rust(`simucleo-circuit`)가 담당하므로 웹과 CLI 테스트에서 같은 결과가 나온다.
- 실행 중 변경을 지원하려면 부품 모델이 연결 변경 시 상태를 안전하게 초기화하거나 유지해야 한다(M3).
